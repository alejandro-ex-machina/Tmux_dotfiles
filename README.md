# Tmux config files

**MI** Configuración, paquetes y preferencias para [Termux](https://termux.dev/).

## Qué incluye

- Tipografía [`Nouveau IBM`](https://www.dafont.com/es/nouveau-ibm.font)
- Configuración de Termux.
- Paquetes
  - Vim
  - Git
  - Python
  - PHP
  - Neofetch
  - cUrl, wGet
  - nettols
  - Pandoc

- Clonado y despliegue de algunos otros de mis repos públicos:
  - quotes
  - printText
  - asciimages

## Cómo se usa

Clona el repositorio, posiciónate en él, ejecuta `bash provision.sh` y ya.
